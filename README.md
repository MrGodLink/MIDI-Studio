# MIDI-to-MP3
MIDI Studio is a MIDI player and MIDI-to-MP3 converter **for Linux**. Sound is synthesized with [FluidSynth](https://www.fluidsynth.org/) and encoded to MP3 with [FFmpeg](https://ffmpeg.org/) (LAME). The interface is bilingual (English / Italian): it follows your system language and can be switched from the toolbar.
